# Cloud Duo Portfolio — Dhanush P × Kabir Ahmed Khan

A premium interactive portfolio built with React, Vite, Three.js / React Three Fiber, Drei, Framer Motion and Lucide.

## Run
1. Install Node.js 18+.
2. In this folder run `npm install`
3. Run `npm run dev`
4. For production: `npm run build`

## Notes
- Resume-derived content is kept faithful to the supplied resumes.
- Replace/add project media in `public/` if desired.
- Social links are the LinkedIn/GitHub links present in the resumes.
